# AI Study Companion

AI-powered learning and growth workspace.

## Overview

AI Study Companion is a full-stack learning platform that helps
learners organize learning projects, study uploaded materials,
interact with a grounded AI Tutor, take adaptive assessments,
track concept mastery, analyze growth, and receive personalized
next-action recommendations.

## Core Learning Loop

Space
→ Project
→ Material
→ Knowledge
→ AI Tutor
→ Quiz
→ Assessment
→ Mastery
→ Growth
→ Analytics
→ Recommendation
